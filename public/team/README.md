# Team Photos

Put all About Us team photos in this folder.

## File naming format
Use lowercase kebab-case:

`firstname-lastname.jpg`

Examples:
- `ravi-sharma.jpg`
- `ananya-patel.jpg`
- `mohit-verma.jpg`

## Recommended image specs
- Ratio: 1:1 (square)
- Minimum size: 600x600
- Format: `.jpg`, `.jpeg`, `.png`, or `.webp`
- Keep face centered

## Team data file
Add team details in `public/team/members.json` and make sure `photo` matches each filename exactly.
